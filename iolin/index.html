iot API hosted · works from anywhere

              
Checks that return PASS, FAIL or ABSTAIN with the evidence behind them, plus the open benchmarks feed. One key for the API and MCP. This page never asks for or stores your key.

              
Base URL
https://api.io-threads.com/functions/v1/iot/v1

                
Auth
Authorization: Bearer iot_… Make a key on your Account page; it's shown once, so copy it then.

                
Limits
Starter 1,000 calls a day, Pro 10,000, Scale 100,000; a key without an API plan gets 402 no_plan. /v1/benchmarks and /v1/checks are public and not counted; /v1/me isn't counted. Plan limits: GET /v1/plans.

                
Errors
401 no_key or bad_key · 429 limit (wait for Retry-After) · 400 bad_request (the message says which field)

              
Endpoints paths as in the full docs: /v1/me is https://api.io-threads.com/functions/v1/iot/v1/me

Privacy, plainly. This page is a demo: replies are pre-recorded and no model is downloaded. Sessions, settings and receipts stay in this browser. If you choose to run a real model here, its files download from Hugging Face the first time, which shows them your IP address. Small models make mistakes.
